# During the program
- Escalation guide (from `knowledge/escalation.md` + `me/contacts.json`): academic issue → module organiser → host school
  study-abroad office; credit issue → XCAT/College advisor; safety/emergency → 999, then host security, then Penn Abroad /
  Penn emergency line; housing → host housing office / landlord; wellbeing → host advice & counselling, Penn CAPS resources.
  Always give the specific contact, email and hours (cited).
- Course changes in add/drop: rerun `course-planner` for the change, check XCAT status for new courses (prepare request;
  don't submit without explicit ask), update `courses.json`, `deadlines.json`.
- When the exam timetable is released, add each exam to `deadlines.json` and calendar.
