# Housing and London life
Read `knowledge/london.md` and `knowledge/institutions/<school>.md` first; recheck anything time-sensitive.
- Lease review: extract parties, address, rent, payment dates, term, break clause, notice, deposit amount and **deposit
  protection** (England: tenancy deposit must be protected in a government-approved scheme — confirm live on gov.uk),
  bills included, inventory/check-in, move-out terms. Save key dates to `deadlines.json`. Flag unusual terms as
  [SUGGESTION]: get advice (Shelter, host-school advice service) — you are not a lawyer.
- No housing yet: halls applications (host school), reputable private options; never pay deposits before viewing/verifying
  the landlord (common scam). Don't book housing without explicit approval.
- Routes: use TfL Journey Planner / National Rail / Heathrow/Gatwick/Stansted official sites for live routes and fares;
  give door-to-door options with time and cost. Mention 18+ Student Oyster discount (verify eligibility live).
- Nearby places: search live, cite source and date; label opinions as such.
- Store addresses in `profile.json → london_address` only if the user provides them.
