# Shared knowledge base
Generic, non-personal facts for Penn students in London. Every page starts with `last_checked` and `recheck_by`.
Each fact line is labelled [FACT] (with source + date) or [UNVERIFIED] (with how to verify). Agents must recheck
time-sensitive facts live before relying on them, and propose changes via `me/core-suggestions.md`.
